# JRE-PA-Simulator

JR 東日本風格列車廣播與車內 LCD 顯示模擬器。

**[English](README.md)**

---

## 安裝

```
your-folder/
├── JRE-PA-Simulator.exe
├── fonts/
├── data/
└── audio/
```

1. **下載** [Releases](https://github.com/ksleungac/pids-jre-simulator/releases) 中的 `JRE-PA-Simulator.exe`,並將整個 repo clone 下來,將 exe 放在 repo 根目錄底下。
2. **安裝字型** — 請將 `fonts/` 資料夾內的全部字型安裝到系統。

> `audio/` 與 `data/` 資料夾內的路線資料不定時更新。如需最新資料,請 clone 此 repo 並定期從 master 執行 `git pull`。

---

## 使用方法

| 按鍵 | 功能 |
|------|------|
| Page Down | 下一則廣播 |
| Page Up | 發車音樂(音樂播放途中再按一次可跳至音樂結尾與關門廣播) |
| End | 暫停 |
| ESC | 離開 |
