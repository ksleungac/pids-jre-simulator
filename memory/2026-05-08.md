**Mid-session bug: `# fmt: off — text` is not a directive.** Black requires the directive line to be EXACTLY `# fmt: off` / `# fmt: on` — trailing text turns it into a regular comment that Black formats through. Hit this when my first-pass markers used `# fmt: off — preserve aligned columns ...`. Black silently formatted the supposedly-marked blocks. Surfaced via the reformatted i18n.py post-Black state. Fix: explanatory text on a separate comment line; directive line bare. Codified in conventions.md § UI code style as a clause on the tuneable-params rule.

**Granularity decision: scope `lint_primitives.py` BANS to grep-shaped primitive bans only.** Not Cycler.paused (one-class-internal, narrow scope, inline CONTRACT covers it). Not the JSON-as-input-grammar architectural pattern (too abstract for grep). The lint serves the auto-loaded conventions.md primitive-ban registry; everything else stays at the principles + inline-CONTRACT layer.
