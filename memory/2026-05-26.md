## Session: Harness reduction — preloaded rules compression + PostToolUse hook

Systematic compression of all preloaded rules files to reduce per-turn token cost. The insight: preloaded `.claude/rules/*` files burn tokens every turn, so they should be compressed aggressively with rationale stripped to one-liners. On-demand skills can afford fuller explanations since they only load when invoked. Mechanical work (commit file classification) can offload to hooks entirely.
