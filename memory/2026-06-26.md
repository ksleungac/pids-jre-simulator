# 2026-06-26

## Session: Font investigation — PixelMplus tested + rejected, MS Gothic confirmed as the gold-standard (non-shippable) reference

Continued the TIMS-chrome font hunt from the post-compaction "free font for download" question. The
whole thing resolved to one structural fact: **small-size pixel crispness comes from embedded bitmap
STRIKES, not render size or supersampling.**

- **PixelMplus10/12 downloaded + tested → rejected as a swap.** Hypothesis was "a different family =
  more kanji detail." False: PixelMplus12 is *also* a 12px grid, so detail is lateral to Ark, not an
  upgrade. And it's JA-only — zh_HK 97.3% (tofus 錄), zh_CN 61.5% — so it can't serve the per-locale
  chrome (Han unification is exactly why the shipped Ark set is one file per locale). Kept on disk in
  `_fonts_eval/` for the niche crisp-20px JA case (10px grid ×2).
- **MS Gothic walk → why it wins, quantified.** User: "i think msgothic is the best." It is — but it's
  recorded non-shippable (MS license + JIS-only zh_CN tofu), so it's the *reference bar*, not a choice.
  The win mechanism: it ships ~13 hand-tuned bitmap strikes (one per px 10–22), each with size-growing
  detail, then smooth outline from 23. Ark has zero strikes (single 12px outline), so 14–22px is the
  12px shape rescaled — no added strokes, and supersampling can't add what was never drawn. That's the
  structural reason "Ark looks worse than MS Gothic" in the 16–22px band (readout @18, buttons @16).
- **Reframed the free-font goal:** not "more kanji" but a **multi-strike bitmap face**. JF Dot Shinonome
  / jiskan16 (PD, strikes 12/14/16) promoted to try-first; benchmark deferred (TODO). Realistic split =
  jiskan16 for always-Japanese station names + Ark for per-locale chrome.

Self-corrected one tooling bug mid-session: the strike-vs-outline detector read RGB only, but pygame
puts AA coverage in the ALPHA channel when rendering without a background → every size falsely read as
a 2-colour "bitmap." Fix: render AA-ON onto an opaque bg so greys land in RGB. (Recorded as a reusable
probe in the WIP harness note.)
