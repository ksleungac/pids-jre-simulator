**Cross-model leak pathology (the session's real lesson):** e235_0 *reuses* e235_1000's `LowerDisplay` manager + shared transfer display rather than copying them. Partial override leaked parent bindings twice — (1) overriding only the kanji/furigana renderers left ENGLISH mode showing e235_1000's linear full-route + 8-station views; (2) the shared transfer display imported e235_1000's `UPPER_HEIGHT`, mis-sizing e235_0's lower region 13px. Same root: inherited infra carries the parent model's renderer instances and dimension constants; reusing-not-copying means you must override/parametrize *every* variant, not the common path. Fixed via same-instance english renderers + `upper_height` param (default = sibling's) + `surf.get_height()`. Codified.
