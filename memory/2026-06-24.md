# 2026-06-24

## Session: TIMS-style setup redesign — page-1 draft + pixel button/text primitive

Visual-judge iteration building the setup / home screen to the JR East TIMS cab look (glossy
raised-bevel blue buttons + low-res pixel text). Durable design home is `WIP_setup_redesign.md`; this
log is continuity only. Draft: `_dev_scripts/setup_redesign_draft.py`; primitive:
`_dev_scripts/button_style_sandbox.py` (+ `_test_button_primitive.py`).

Primitive grew two reusable pieces (test green, justify path byte-identical): `draw_lowres_text` gained
`align` (justify / center) + `pad` (margin, decoupled from inter-char gap), and `lowres_fit_k` (the k
it would pick — pin a row of elements to ONE uniform size via the min).

Decisions (full detail in the WIP doc):
- **Font = Ark Pixel 12px monospaced, per-locale (latin/zh_hk/zh_cn), ONE shippable build.** IRL TIMS
  is monospaced; CJK is full-width either way, mono also squares Latin + numerals. MS Gothic ruled out
  (non-redistributable + JIS — no Simplified, tofus 简; Ark resolves it).
- **Pixel is a small-size aesthetic** — crisp at k=2, chunky upscaled. The big-button pixelation was
  *oversizing*; fixed by shrinking cards to the 3–4-across footprint, NOT a smooth fallback. The
  reframe: keep elements small enough to render at low k, then pixel reads as intentional everywhere.
- Yellow = pressed (momentary), not selected. Decisive / nav actions: pressed reaction beat → ~0.5 s
  blank → repaint. Setup is its own taller window (610), not LCD-bound.
- TIMS numeral recipe: full-width forms + ~80% horizontal squeeze (nearest-scale, keeps pixels) —
  reusable for train numbers / diagram codes / clocks.

Next (user compacts first, then we continue): **the full-width numeral gap is still too wide at 80%** —
tighten the condense. Then the 6-step graduation (fonts → `fonts/`; primitives → a chrome `widgets.py`
via `/third-man`; drop the sandbox hatches; perf-cache the bevel; wire `setup.py`; codify + dissolve)
BEFORE building other pages.
