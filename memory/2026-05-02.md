## Session: yellow-square nag indicator + dual-stream audio (PA/STA overlap)

### Yellow PA-hint square reframed

Was treated as a static "this stop has multi-PA" badge. Reframed as a per-press nag indicator: blink while extras remain, **disappear** (not solid yellow) once the last extra is started. APPROACHING_EARLY also gates on `is_pa_playing()` so the square doesn't flash during the auto-fired pa[0] passive-listening window. STOPPING does NOT gate on audio: every pa_at_station press is user-initiated, so flashing during user-pressed playback isn't deceptive nag — gating it would just strobe the square off-and-on with each press.

Insight surfaced: APPROACHING vs STOPPING are asymmetric on auto-fire. Promoted to CLAUDE.md § "App state machine".

### Dual-stream audio (PA + STA overlap)

Previously single-stream (`mixer.music`); pressing Page Up during PA stopped the PA, and vice versa. IRL these are different sources (in-train PA vs platform melody) — sim now mirrors. PA stays on `mixer.music`, STA moved to `mixer.Channel(0)` via `mixer.Sound`. Promoted to CLAUDE.md § "IRL display conventions" (the audio bullet sits with the display bullets since both are IRL conventions).

`sta_cut` lost its `start=offset` capability (Sound.play has no offset arg) — handled by slicing leading samples off the normalized array before writing the temp file.

### pygame Channel.get_busy quirk

`Channel.get_busy()` returns True even on a paused channel, so naive `is_sta_playing()` would block "Page Up after End" from playing fresh (taking the restart-from-sta_cut branch instead). Fixed via explicit `_sta_paused` flag set in `pause_sta()` / `pause()`, cleared in `_load_and_play_sta()` / `unpause()` / `stop()`. `mixer.music` doesn't have the same quirk per pygame, so PA gets no equivalent flag (deferred — see review entries).

### End-key priority pause

When both streams play, End pauses STA only — PA carries info, platform melody is the noisier one to silence. KEY_REPEAT_DELAY throttle on the End handler prevents a single keypress from collapsing across consecutive frames into "pause STA → pause PA" double-pause.
