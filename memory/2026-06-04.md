## Session: re-entry two-probe consensus + panel re-aligning indicator

Hardened the auto-driver re-entry path (TODO #1). Previously `_maybe_reentry` acted on a *single* OCR cycle's read — a mid-transit click-jump snapped the LCD forward immediately, and a lone transient misread while parked could fire a spurious silent-advance.

**Why consensus pays (the deciding asymmetry):** re-entry is forward-only and irreversible — it never retreats Layer 1. So a false positive sticks the LCD +1 ahead of reality until the user click-jumps back (no self-correction, unlike a held-key fire that self-retries). The genuine cases it serves (cold boot, mid-transit click-jump) pay only one interval (~5s) of latency to wait for a second probe — cheap, and those are exactly the moments the user just acted, so a brief settle reads as intentional.

**Consensus rule (settled with user, rule-by-rule):** commit only when two *consecutive* cycles resolve to the same target. Always the latest 2 reads (sliding window of 2), not first-vs-last — any different target (incl. 1A→1B mid-wait) OR a no-op re-bases the latch. Split `_maybe_reentry` into a pure `_resolve_reentry_target` (no mutation) + the consensus commit; `_Detector.reentry_latch` holds the prior cycle's target.

**Panel grammar decisions:** the wait surfaces as an amber "Re-aligning…" chip (`reentry_pending` status field, `panel.realigning` i18n) — supersedes the Played count / green chip. Discovered the `●` transient-chip bullet (and the `→` arrow) blank in en because HelveticaNeue is Latin-only; routed `●` through the name-font for *both* chips (green auto-played + amber re-aligning) so it shows in en. Collapsed the `A → A` segment to a single station when parked (`seg_start == curr_stop`).

**Offline verification (no game on this machine):** the consensus logic is pure state-machine — OCR pixel-reads are the only game-dependent part. `_dev_scripts/verify_reentry_consensus.py` drives synthetic `(speed,dist,badge)` probe sequences through a real `_Detector` + fake sim, 9/9 cases pass. `_dev_scripts/preview_panel.py` renders the panel in any state across all 3 locales for visual check.
