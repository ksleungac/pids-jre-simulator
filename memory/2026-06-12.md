## Session: E235-0 5-station badge — unified on the shared renderer + fixed the font face

Continued E235-0 calibration work. Hand-tuned the 5-station view in the editor (per-station marker/badge/name sizes; upper-LCD layout against the 130px IRL overlay), made the current-stop pentagon's apex angle a tuneable (`m0_a`, degrees, default −125° = old aim-at-m1), then did the session's real work: a badge refactor.

### The badge detour — and why the Wikipedia template was a red herring
User noticed the 5-station badge "looked wrong" and thought the Wikipedia `Template:JRSN` was a more authoritative source to adopt. Chased it: expanded the template via the MediaWiki `expandtemplates` API → it's **pure CSS** (a white rounded box, colored border, line letters + number as browser-font text). No per-station artwork to download, and the browser font is *not* Frutiger. So the template is actually *lower* fidelity than what the repo already had.

The actual cause of the wrong look: the 5-station `_draw_jy_badge` was calling the shared `draw_station_code_badge` but with **bad params** — `ring_black=0` (no black frame) and the **wrong fonts** (`ShinGoPr6N` + `HelveticaNeue` instead of the upper LCD's `NeueFrutigerWorld-Bold`, the real JR signage face). Same renderer, mis-driven. Fixed by scaling the upper-LCD param set by `b/68` (upper badge is 68px).

### Font face hardcoded — `draw_station_code_badge` no longer accepts a font
User escalated to a rule: the badge function *"shouldn't even accept different font."* Refactored the helper to hardcode the face (`NeueFrutigerWorld-Bold` via a module-level cached `_badge_font(size)`) and take only point SIZES. All 4 callers migrated (e235_0 + e235_1000, upper + lower-8), dead `__init__` font objects removed.

Key constraint that shaped it: **size can't be a single fixed ratio.** Upper badge 68px→18/22pt (~0.27/0.32); 8-station 22px→8/11pt (~0.36/0.5, chunkier so tiny text stays legible). So: face fixed, size stays caller-controlled. Verified no regression on the shipped e235_1000 8-station view (sizes unchanged, face was already Frutiger).
