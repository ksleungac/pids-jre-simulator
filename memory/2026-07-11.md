## Session: TIMS tutorial port + band-Home-everywhere + setup-redesign parity/backlog

Continued the TIMS setup redesign — closed the tutorial screen, band-nav consistency, OOBE, and swept the
remaining setup backlog to parity so only the `--tims`-default flip is left for the final check.

**Tutorial port — subclass, not rewrite.** The legacy `tutorial.py` interactive walkthrough went into the
TIMS flow as `BasicTutorial(Tutorial)` (`setup_tims/tutorial_basic.py`): inherit the ENTIRE step machine,
override ONLY layout methods to reflow the wide LCD+side-panel into the 730 band window vertically. This
reconciled two hard constraints the user stated emphatically — "keep the hands-on demo / don't lose any
interactivity" AND "leave the original tutorial source intact." Hit-testing follows for free because the
overridden draws populate the same `_phase_rects`/`_btn_rects` the inherited handlers read. The design
LANDED DIFFERENTLY from the WIP's tab-shell master-detail plan (that was awkward in the narrow frame) — a
selection MENU (`tutorial_select`) → the tutorial, no persistent tab column. WIP § Tutorial screen rewritten.

**Band Home = straight home + beat on EVERY page.** Deep pages return a `"home"` sentinel that parents
bubble up (route/model → pa_setting; tutorial_basic → tutorial_select → home). `ocr_setting` was the last
holdout. Pathology avoided: `ensure_consent` returned a bool consumed by `if ensure_consent(...):` — a
truthy `"home"` string would read as *consent-accepted*. Fix splits the `"home"` bubble out BEFORE the
truthy accept check at every caller. (This is why sentinel returns that overlap a truthy domain are a trap.)

**`\n`-tofu.** The step-8 recap rendered tofu boxes where its `\n` newlines were — AA-off lowres wrappers
treat `\n` as an ordinary char and Noto has no glyph for it. Split hard newlines in the caller first. Codified.

**OCR-launch "crash" was a ghost.** The WIP's KNOWN-ISSUE crash lived in the retired `auto_input.draw_debug_panel`;
the live drive already renders the graduated `status_band.render`. Reproduced headless across frames with the
live status dict — clean. Not a real blocker.

Put it in the permanently-blank 月台 (IRL platform) table row, relabeled 列車型號 — the row is the same 番線
