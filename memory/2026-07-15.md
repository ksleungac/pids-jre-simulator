**Audit-blindspot incident:** the button-state audit caught the dead-press + missing-beat (its own shortlist A.1/A.4) but MISSED "no set button." A state-inventory ("does each button have the right state") structurally cannot see an *absent* affordance — absence isn't a state. User flagged it ("how come your scan didn't find that"); the honest answer is state-audit ≠ completeness-audit. (User is drafting a middle-ground review skill for this class on a separate PC.)
