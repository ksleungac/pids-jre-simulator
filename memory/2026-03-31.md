## Ralph Loop Skills Implementation

### Background
User wanted to implement a "Ralph loop" pattern but doesn't have Codex. Created two skills inspired by Codex pattern but adapted for Claude Code.

### Skills Created/Modified

#### 1. `review-dirty` Skill
- **Purpose**: Reviews dirty code changes using Agent tool
- **Agent**: "CodeReviewer" with sonnet model
- **Output**: Structured JSON feedback with issues list
- **Triggers**: `/review-dirty`, `review`, `review changes`, `review dirty code`

#### 2. `review-plus-fix-relentlessly` Skill
- **Purpose**: Implements Ralph loop (review → fix → review)
- **Pattern**: Reviewer agent provides feedback → Main agent (me) fixes → Loop
- **Max cycles**: 10 (configurable)
- **Stop condition**: No issues found or max cycles reached
- **Triggers**: `/review-plus-fix-relentlessly`, `loop to fix dirty`, `review+fix`

### Key Learning: Correct Ralph Loop Pattern
Originally misunderstood the pattern - thought we needed separate "reviewer" and "fixer" agents. Actually:

**WRONG pattern (initial implementation)**:
Reviewer Agent → Fixer Agent → Loop

**CORRECT pattern (final implementation)**:
Reviewer Agent → MAIN AGENT (me) fixes → Loop

The main agent (Claude Code user) should be the fixer, not spawning another agent. Matches original Codex pattern where main agent uses Codex for review, then fixes itself.
