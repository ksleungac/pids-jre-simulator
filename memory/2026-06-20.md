## Session: E235-0 open-horseshoe full-route (non-Yamanote)

Replaced the E235-0 FULL-slot's E235-1000 linear fallback with a new `OpenRouteFullRouteDisplay` — the Yamanote racetrack with **one end cap dropped** (a horseshoe). Subclasses `CircularFullRouteDisplay`, reusing its marker primitives and overriding only the JY-keyed pieces to be stop-index keyed + linear. Manager now: 山手線 → circular, else → horseshoe (English mode shares the instance, kanji-only).

Walked the design one decision at a time (user co-design):
- Shape: open on the left (two flat terminals = origin + dest), fold on the right. `_draw_track` draws the closed racetrack then whitens the left cap + each row's left stub.
- Row split: bottom = `⌈N/2⌉`, top = rest, shared pitch, **right-aligned at the fold**.
- **No sweep** — fit-to-rows by shrinking pitch. This is best-effort/out-of-spec (E235-0 is Yamanote-only IRL), so simplicity wins over a window-flip; worst real case is Keihin-Tōhoku 46 → 23/row. Revisit only if a real route reads too cramped.
- Band grays behind the train (`_draw_passed_band` clip-redraws gray over the folded passed path); boundary follows `cursor_pos`.

WHY worth keeping:
- **Cascade unchanged.** User: "the cascade sweep moves the same, no different." So the APPROACHING pointer stays anchored on `curr_stop`; `cursor_pos` only drives the dimming. Did NOT adopt E235-1000's cursor-stepping pointer.
- **Latent crash exposed, not introduced.** The inherited minute chain does `cumulative += stop.get("time", 0)`; passing stations carry `time: None` → `None + int`. Yamanote never hit it (no passing stations); the horseshoe did. `_ahead_indices` now skips passing stations (they get chevrons, not numbers), which both fixes the crash and matches E235-1000.
- **pre_stops shift the runtime `--stop` index.** sobu/1217F has 18 pre_stops, so preview `--stop 10` landed on 千葉 (route.json idx 9), not 東千葉 — a diagnosis detour resolved by reading route.json + the pre_stops count, not by trusting the arg. Verify-before-claiming held.
- **Scope discipline.** User called it end at functional-not-finetuned: don't fine-tune best-effort support; if non-Yamanote routes ever deserve real fidelity, build E233-0/Chūō (in-spec) instead. Reinforces the per-model IRL-line-scope policy.
