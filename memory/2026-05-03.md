### Algorithm enhancements (all preserve Rules 1-4 cascade)

1. **Capped lex-maximin row-grouping** — `gap_cap = 2·margin_x`, padded to `max_rows`, `-num_rows` tiebreak, uncapped fallback. Fixed (1,1,1) regression for sparse 3-entry single-row cases.
2. **Single-row equal-spacing for row 0** when `len(rows) == 1`, with `side_pad = (W − Σ) / 14` to bias sides slightly larger than inters per IRL preference.
3. **Rule 1 canvas-fit defensive check** (k ≥ 1) catches wide row-R entries inheriting narrow row-0 anchors. Caught Hamamatsuchō flat overflow once Tokyo Monorail's 330px width was introduced.
4. **Blueprint placement enhancement** — when max-Σ row is NOT row 0, that row is placed first via equal-spacing as the cascade seed instead of waiting for reactive Rule 4 + track-back. When max-Σ IS row 0, behaviour unchanged. Rules 1-4 cascade fully preserved for non-blueprint rows; Rule 4 track-back skipped only in blueprint mode (since shifting the seed would break it). Hamamatsuchō flat improved (yamanote at x=90, balanced sides). Shimbashi flat regressed cosmetically (rows 0/1 cramp left when blueprint=row 2) — accepted, follow-up logged for Rule 1 enhancement.
